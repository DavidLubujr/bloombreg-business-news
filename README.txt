MANUAL DEPLOYMENT
1. Extract this ZIP.
2. Visit https://app.netlify.com/drop and sign in.
3. Drag the public folder onto the upload area.
4. Open your assigned HTTPS Netlify URL. It opens directly on the floating cyborg awareness page.
5. For reliable preview images, edit public/index.html: replace both content="/assets/cyborg-floating.png" values with content="https://YOUR-SITE.netlify.app/assets/cyborg-floating.png" using your actual URL. Upload public again.
6. Paste the full URL into a fresh message and wait for the preview.

AUTOMATED DEPLOYMENT
Import the whole project from a Git repository into Netlify. netlify.toml runs node build.mjs and publishes dist. The build automatically uses Netlify's URL environment variable for absolute preview image URLs. No dependency installation is needed.
